# Monitron UI Redesign Proposals (Generated via Stitch)

This directory contains high-fidelity redesign concepts and interactive prototypes for **Monitron**, generated using Google Stitch under the project `projects/6316834483884914335` (**Monitron App Redesign**).

To avoid the ubiquitous "dark slate with cyan glow" look, we created **three distinct visual aesthetics** across five screen concepts:

---

## The 3 Design Directions

### 1. 🎛️ Variant A: *Precision Instrument Studio* (Teenage Engineering & Dieter Rams Braun)
- **File**: [`screen-variant-industrial.html`](file:///D:/Dev/code/monitron/docs/redesign-proposals/screen-variant-industrial.html)
- **Palette**: Warm milled anodized aluminum & sand ivory (`#EBE7DF`, `#F4F1EA`, `#DFDBD2`), matte black hardware buttons (`#18181A`), **International Safety Orange (`#FF5722` / `#FF4500`)**, and **Cadmium Yellow (`#FFB300`)**.
- **Philosophy**: Completely rejects generic digital SaaS tropes (no translucent blurs, no floating cards, zero blue/cyan). Surfaces feel like physical Euro-rack studio mixing gear, analog tape decks, and precision instrumentation.
- **Key Elements**:
  - Mechanical push-buttons with stamped debossed uppercase DIN labels (`VOL_01`, `BRIGHT_10`, `VCP_60`).
  - Heavy linear fader with knurled aluminum handle and safety orange position line.
  - 20-segment stepped LED ladder / VU-meter bar.
  - Rotary calibration bays with stamped degree markings.
  - Modular patchbay-style port cards with physical jack sockets.
  - Emergency guarded flip switch for display standby.

### 2. ⚡ Variant B: *Amber Phosphor Avionics & Cyber-Deck Terminal*
- **File**: [`screen-variant-amber-phosphor.html`](file:///D:/Dev/code/monitron/docs/redesign-proposals/screen-variant-amber-phosphor.html)
- **Palette**: Deep pitch carbon void (`#08090C`, `#0E1015`), **Monochromatic 590nm Amber Phosphor (`#FFB000`, `#FF9100`, `#FFC107`, bloom `#FFE082`)**, with zero cyan/purple.
- **Philosophy**: Inspired by military avionics, retro-futuristic CRT flight-deck terminals, and cyber-decks. Uncompromising high-density telemetry.
- **Key Elements**:
  - CRT scanline grid texture and warm cathode ray phosphor bloom.
  - Oscilloscope audio waveform curve and segmented digital ladder meter.
  - Dual 270° circular avionics HUD radar gauges for Brightness and Contrast with glowing needle sweeps and crosshairs.
  - Ultrawide radar display visualizer with beam sweep for input topology.
  - ASCII-styled structural borders, cockpit push-pads, and caution hazard-hatch stripes.

### 3. 🖥️ Variant C: *Precision Optics Dark Utility* (Modern macOS / Raycast Style)
- **Files**:
  - [`screen-1-main-dashboard.html`](file:///D:/Dev/code/monitron/docs/redesign-proposals/screen-1-main-dashboard.html): All-in-one monitor control hub.
  - [`screen-2-settings.html`](file:///D:/Dev/code/monitron/docs/redesign-proposals/screen-2-settings.html): 4-tab settings and configuration modal.
  - [`screen-3-inputs.html`](file:///D:/Dev/code/monitron/docs/redesign-proposals/screen-3-inputs.html): Dedicated 32:9 topology view with source matrix.
- **Palette**: Deep dark slate/zinc (`#090D12` / `#101419`), frosted glass substrates, **Electric Cyan (`#06B6D4`)**, and **Emerald Green (`#10B981`)**.
